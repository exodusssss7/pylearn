## Small steps. Real Python.

PyPerky is a beginner-friendly Python learning app. Plain-language explanations and everyday examples come before the exercises, so you can understand the idea before writing the code.

- **Learn by doing.** Run Python, predict output, fill code blanks, put lines in order and write your own programs.
- **Choose your path.** Continue the next unfinished lesson or search for a topic. Every lesson is open from the start.
- **Practice your way.** Try 91 guided skill cards or experiment in the free-code playground.
- **Keep your momentum.** Local progress, saved code drafts, XP, day streaks and seven ranks track your work.
- **Make it comfortable.** Editors include indentation and punctuation tools. Sound is optional, and motion respects reduced-motion settings.

## Your learning path

| Unit | What you will build on |
| :--- | :--- |
| 01 · Python basics | Text output, quotes, numbers, variables, conditions and your first loops |
| 02 · Strings & lists | Joining text, indexing, lists and a guest-list project |
| 03 · Operators & loops | Comparisons, Boolean logic, `while`, `break` and a countdown |
| 04 · Functions | Parameters, return values, local variables and reusable code |
| 05 · Dictionaries | Keys, values, updates, membership and a profile card |
| 06 · Input & numbers | `input()`, type conversion, arithmetic and a snack bill |
| 07 · Files | Reading, writing and appending text in a temporary practice workspace |
| 08 · Exceptions | `try`, `except`, `else`, `finally` and useful error handling |
| 09 · Classes & objects | Instances, attributes, methods, `self` and `__init__` |
| 10 · Lists of dictionaries | Records, nested lookups, filtering and totals |
| 11 · Modules & JSON | Imports, `math`, aliases and JSON round trips |
| 12 · Reading tracker | Bring classes, validation, files and reports together |

## Fits your screen

A focused single column on a phone. A wider course grid on a tablet. Explanations beside code on desktop. PyPerky adapts to portrait, landscape and wide screens while keeping navigation and learning controls reachable.

## Your progress stays yours

Progress and code drafts are saved in your current browser on this device. Use the same browser to pick up where you stopped. Python runs in a browser worker, and input exercises collect answers before running your program.

### New in v1.6

- A short, skippable first-run welcome. Existing learners keep their path; the tour can be reopened from Profile.
- Four original animated buddies: Perky, Mint, Nova and Pip. Choose one during welcome or change it in Profile. Respects reduced-motion settings.
- Wrong answers offer **Try again** or **Skip step**. No forced rewrite, and no XP for a skipped step. Finishing the lesson still counts as finishing the path; unanswered steps are listed separately in **Review**.
- Review opens the exact skipped question. Answer it correctly to clear it. The queue, buddy choice, progress and code drafts stay on the current browser/device.
- Guided practice has Back / Next skill controls. Your saved code draft is kept when you switch skills.

No accounts, analytics, paid service, build step or new third-party runtime dependency was added. Clearing browser storage removes local progress and preferences.
