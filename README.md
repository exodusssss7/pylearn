# pylearn v0.6

Python from zero in small, interactive steps.

## Unit 1
11 lessons: Say hello, Words & quotes, Numbers, Variables, Text + numbers, True or false, If, Else, Repeat with for, Counting with range, and a Countdown mini project.

Every lesson begins with a plain-language concept introduction and a symbol guide. Lessons include common mistakes, worked examples, live Python runs, output prediction, code blanks, tap-to-order code and typing challenges. Complete lessons in order or replay completed lessons. Progress, XP and day streak are saved in this browser.

## Limits
Three units are available, not a complete Python course. Typed challenges check Python syntax-tree structure, not exact message wording. Different messages, spelling and capitalization inside strings are accepted. Python instruction names and variable references still follow Python case rules. These checks are educational, not a proof that every possible solution is correct. Hints are available after mistakes; automatic easier replacement exercises are not implemented. Text-output playground only: no interactive input(), graphics or package installation. Python downloads from jsDelivr on first use, so internet is required. Clearing browser storage removes progress. There are no accounts, cloud sync, backend or paid services. Not a secure sandbox for other people's untrusted code.

## Built with
Plain HTML, CSS and JavaScript; Pyodide 0.29.0 in a Web Worker; Nunito from Google Fonts. Hosted on GitHub Pages.

## Practice and audio
Twenty-seven guided skill cards plus a free-code playground. Mistakes get specific guidance for quotes, parentheses, names and indentation. Correct answers in a row raise the same chime along a major scale, capped at one octave to avoid shrill pitches. A wrong answer resets it; the streak is per session. Tap, retry and completion keep separate effects. Sound can be muted in Profile; the setting stays on this device. Effects: Kenney Interface Sounds, CC0, downloaded from https://opengameart.org/content/interface-sounds . Original license is included in audio/LICENSE.txt. These are pre-produced interface effects, not claimed to be field recordings.

## Block companion
Original pylearn SVG/CSS artwork reacts to correct answers, retries, combos, code runs and completion. Character motion uses transform and opacity, follows the display refresh rate, and respects reduced-motion preferences. Actual frame rate depends on the device. No LEGO artwork, branding or affiliation.

## Unit 2
10 lessons: joining strings, character counts, string indexing, making lists, list indexing and length, replacing an item, append, list loops, nested conditions, and a guest-list project. Lessons introduce terms before using them; existing progress is preserved.

## Unit 3
11 lessons: updating variables, subtraction, equality, comparison boundaries, elif, and/or/not, while, break, and a while countdown project. Conditions and updates are taught before while loops.
